# HostGPT AI — نسخه اجرایی اولیه 0.1

**توجه:** این نسخه وب‌اپلیکیشن و API محلی است؛ GPT اختصاصی ChatGPT یا پلاگین رسمی نیست. MCP فعلی فقط دو ابزار خواندنی آزمایشی دارد. برای اتصال از داخل ChatGPT لازم است روی HTTPS پایدار مستقر، با احراز هویت و ابزارهای معتبر تکمیل و از مسیر پلاگین متصل شود.


**این ZIP واقعاً حاوی کد برنامه است، نه فقط تصویر یا پرامپت.**

## امکانات آماده

- رابط وب فارسی RTL و نشان انتخاب‌شده HF
- ورود مدیریتی با نشست HttpOnly و محدودیت تلاش برای ورود
- چت با Ollama محلی (پیش‌فرض)، Ollama Cloud، Gemini و Grok؛ از طریق بک‌اند
- نمایش مدل‌های نصب‌شده Ollama
- مشاهده مخزن‌ها و پوشه‌های GitHub با توکن سرور
- آپلود و بررسی ZIP با محدودیت اندازه، کنترل CRC، رد traversal و حذف فایل‌های محرمانه
- ایجاد **شاخه جدید + Pull Request** برای واردکردن ZIP (بدون تغییر مستقیم main)
- نمایش وضعیت اتصالات و بررسی پینگ MongoDB اختیاری
- یک نمونه MCP با دو ابزار فقط خواندنی و توکن مستقل

## آنچه هنوز ساخته نشده

- مدیریت واقعی SSH/SFTP/cPanel و استقرار خودکار روی هاست
- پنل مدیریت رمزها و OAuth؛ در حال حاضر تنظیمات فقط فایل `.env` سمت سرور هستند
- سامانه کامل کاربری، بکاپ/rollback و ممیزی حرفه‌ای
- سازگاری و انتشار رسمی MCP/Plugin در ChatGPT (MCP فعلی صرفاً نمونه حداقلی است)
- استقرار دائمی یا اتصال واقعی به حساب‌های شخصی شما؛ هیچ کلیدی آزمایش نشده است

## مهم‌ترین کار امنیتی قبل از استفاده

همه API Keyها و رمز MongoDB که در گفتگو ارسال شده‌اند را **باطل/تعویض کنید**؛ اگر آن‌ها را در فایل یا مخزن دیگری قرار داده‌اید آنجا هم پاک‌سازی کنید. هیچ‌کدام از اطلاعات ارسالی شما در این پروژه درج نشده‌اند.

## اجرای محلی و رایگان

1. Node.js نسخه 20 به بالا را نصب کن.
2. پوشه ZIP را استخراج کن.
3. فایل `.env.example` را با نام `.env` کپی کن؛ یک رمز مدیریتی **جدید، قوی و حداقل ۱۴ کاراکتری** در `ADMIN_PASSWORD` بگذار.
4. در ترمینال پوشه برنامه اجرا کن:

```bash
node server.mjs
```

5. در مرورگر برو به `http://127.0.0.1:3000` و رمز مدیریت را وارد کن.
6. برای کارکرد واقعی Ollama باید آن را نصب و روی همین کامپیوتر اجرا کرده باشی؛ مثلاً:

```bash
ollama pull qwen2.5-coder:7b
ollama serve
```

اگر Ollama از قبل اجراست، دستور `ollama serve` دوم لازم نیست.

## اتصال سایر مدل‌ها

در فایل `.env` خصوصی و فقط با کلیدهای **جدید**:

- `OLLAMA_CLOUD_API_KEY` و `OLLAMA_CLOUD_MODEL`
- `GEMINI_API_KEY` (کلید رسمی Google AI Studio)
- `XAI_API_KEY` (کلید رسمی xAI)

**مدل‌های ابری ممکن است پولی باشند.** Grok به‌صورت پیش‌فرض غیرفعال می‌ماند تا خودت کلید را اضافه کنی.

## اتصال GitHub

یک Fine-grained PAT یا GitHub App با مجوز حداقلی لازم است. آن را در `.env` خصوصی با کلید `GITHUB_TOKEN` قرار بده. برای ساخت blob، commit، شاخه و PR، دسترسی لازم به Contents و Pull Requests مخزن لازم است. آپلود ZIP با تأیید دستی و PR انجام می‌شود؛ **main خودکار تغییر نمی‌کند**.

## MongoDB

`MONGODB_URI` اختیاری است. برای تست اتصال، به‌صورت جداگانه `npm install` کن تا بسته `mongodb` نصب شود (این پروژه بدون MongoDB نیز اجرا می‌شود). اطلاعات پایگاه داده هنوز وارد منطق چت نشده‌اند.

## MCP

برای فعال کردن نمونه خواندنی، `MCP_ACCESS_TOKEN` را در `.env` بگذار. نقطه اتصال: `POST /mcp`. تنها ابزارهای `ai_provider_status` و `project_info` فعال هستند. این کد هنوز یک پیاده‌سازی کامل و بررسی‌شدهٔ سازگار با کلاینت‌های عمومی MCP نیست و نباید فعلاً به‌عنوان پلاگین رسمی منتشر شود.

## هاست ایرانی / دامنه .ir

برای نسخه آنلاین، هاست Node.js ایرانی با HTTPS، دسترسی خروجی به APIهای دلخواه، اتصال اختیاری به MongoDB و توان اجرای پردازش مورد نیاز انتخاب کن. Ollama محلی به سروری با RAM کافی نیاز دارد؛ **هاست اشتراکی معمولی معمولاً Ollama را اجرا نمی‌کند**. می‌توان Node.js را روی هاست و Ollama را روی دستگاه جدا با تونل امن راه‌اندازی کرد.

سرویس را مستقیماً با IP عمومی باز نکن. اگر پشت reverse proxy HTTPS با دامنه قرار گرفت، `HOST=0.0.0.0` و `COOKIE_SECURE=1` بگذار و دسترسی مستقیم به پورت Node را از اینترنت ببند. کلیدها نباید در `public/` یا GitHub Pages ذخیره شوند.
