# افزونه اختیاری Heretic برای FEZI HostBridge AI

این بسته فقط **ثبت افزونه و راهنمای یکپارچه‌سازی** است؛ Heretic نصب یا اجرا نشده و دکمهٔ فعال‌سازی زنده به UI اضافه نشده است.

منبع: https://github.com/p-e-w/heretic — مجوز AGPL-3.0

## نصب در ماشین دارای سخت‌افزار کافی

```bash
python -m venv .venv
source .venv/bin/activate
# ابتدا PyTorch سازگار با سخت‌افزار خود را نصب کنید
pip install -U heretic-llm
heretic Qwen/Qwen3-4B-Instruct-2507
```

فرمان آخر در پیکربندی پیش‌فرض مدل را برای کاهش امتناع اصلاح می‌کند؛ برای کاربردهای دیگر فایل‌های config.noslop.toml و config.nosyco.toml را از مخزن رسمی بررسی کنید. مدل اصلی را نگه دارید و خروجی را جداگانه ذخیره و ارزیابی کنید.

Heretic **پلاگین عمومی برای Ollama یا موتور تصویر و ویدیو نیست**؛ روی وزن برخی مدل‌های زبانی قابل‌بارگذاری عمل می‌کند. مدل اصلاح‌شده را پس از ارزیابی و تبدیل مناسب می‌توان در Ollama استفاده کرد.

## نقشه یکپارچه‌سازی در برنامه

۱. افزونه را در فهرست «آزمایشگاهی / مدل‌های محلی» نمایش دهید؛ وضعیت پیش‌فرض: نصب‌نشده.
۲. اجرای Heretic فقط در worker جداگانه، با اجازه مدیر، مسیرهای محدود و سقف منابع باشد.
۳. خروجی به‌عنوان مدل مستقل با شناسه، نسخه و گزارش ارزیابی ثبت شود.
۴. در چت انتخاب مدل اصلاح‌شده ممکن شود؛ بدون ادعای پشتیبانی از Stable Diffusion/FLUX/Wan.
۵. هنگام توزیع عمومی الزامات مجوز AGPL و مجوز مدل پایه را رعایت کنید.
